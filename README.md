# Smart Contract Audit Reports

## About

This repository contains two kinds of smart contract audit reports:

1. **Educational audits** based on material from [Cyfrin Updraft](https://updraft.cyfrin.io/).
2. **Real competitive audits** conducted through public audit platforms and competitions.

The Cyfrin Updraft reports are not intended to be simple reproductions of the course walkthroughs. I use the original material as a starting point and expand on it with additional analysis, testing, Proofs of Concept, and independent findings.

This repository serves as a public record of my progress in smart contract security research and auditing.
